## Shared

Есть ситуации, когда необходимо создать связь между двумя shared-компонентами, тогда лучше создавать слой еще ниже, чтобы не нарушать концепцию FSD

### Пример

Компонент, который возвращает объект с иконками Icon.Check. Этот компоненнт используется в компоненте Tag, который отображает иконки.

Решение: Вынести Icon в assets


### Cross-import

Возможность импортировать из одного слайса в другой. в слайсе создается  папочка @x, в которой объявляются файлы с обозначением принимающего слайса и оттуда принимающий слайс импортирует данные


## Как переводить новые проекты на fsd

1. Сначала выделить app и pages
2. Выделять shared
3. Если рефакторинг/новая фича, то разбивать в features/entities/widgets
4. Если есть время на рефакторинг, перетаскивать существующие компоненты в необходимые слои
